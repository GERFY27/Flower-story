ЦВЕТОЧНАЯ ИСТОРИЯ — PWA-пакет для iPhone

Файлы:
- index.html — сама игра
- manifest.webmanifest — имя, иконка и режим приложения
- sw.js — кеширование для запуска без сети после первой загрузки
- icon-192.png и icon-512.png — иконки

Как установить на iPhone:
1. Сначала разместите ВСЕ файлы из этой папки на HTTPS-хостинге (например, GitHub Pages).
2. На iPhone откройте опубликованный адрес именно в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. Включите «Открывать как веб-приложение», если переключатель показан, затем нажмите «Добавить».

Важно:
- Нельзя установить PWA прямо из ZIP-файла: ей нужен HTTPS-адрес.
- Игровой прогресс хранится локально в браузере на этом устройстве. Очистка данных Safari может удалить сохранение.
- Это персональная веб-версия, не IPA и не публикация в App Store.
